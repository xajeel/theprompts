# Unpublished prompts

Markdown prompts in this folder are stored in the same GitHub repo as the website, but they are **not** listed on the GitHub Pages site.

Pages is set to publish only `docs/`. This folder stays off the website.

If the repo is public, these files are still visible on GitHub.com. Use a private repo for anything you do not want other people to read.

## Add a prompt

1. Copy `_template.md` to a new file, for example `code-review.md`.
2. Fill in the title and prompt.
3. Commit and push.
